# Weather Dashboard

A simple weather dashboard that displays live weather information for a city entered by the user.

## Features

- Search weather by city
- Current temperature
- Weather description and icon
- Feels-like temperature
- Humidity
- Wind speed
- Loading state
- Error handling
- Responsive design

## API

This project uses the OpenWeather API.

## Setup

1. Get an API key from OpenWeather.
2. Create a file called `config.js` in the project folder.
3. Add the following line:

   const API_KEY = "YOUR_API_KEY_HERE";

4. Replace `YOUR_API_KEY_HERE` with your API key.
5. Open `index.html` using Live Server.

The `config.js` file is ignored by Git so the API key is not uploaded to the repository.
